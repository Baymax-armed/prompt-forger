Privacy Policy for PromptForger

PromptForger does not collect, store, transmit, or sell any personal data.

The extension operates entirely locally within the user’s browser. It detects text input fields on webpages and enhances user-provided prompts directly on the page. No browsing history, personal information, authentication data, financial data, or location data is collected.

All user preferences (such as enhancement mode or UI position) are stored locally using Chrome’s storage API and remain on the user’s device.

PromptForger does not use analytics, tracking scripts, or remote code execution.
