PromptForger – Privacy Policy

Last Updated:

Prompt-Forger ("the Extension") respects your privacy and is designed with a strict no-data-collection policy. This Privacy Policy explains how information is handled.

1. Data Collection

PromptForger does not collect, store, transmit, or sell any personal data. The extension operates entirely locally within the user's browser.

2. Website Content Access

The extension detects text input fields on webpages in order to enhance user-provided prompts directly on the page. This access is limited strictly to providing the extension’s core functionality.

  • No browsing history is stored
  • No personal information is collected
  • No authentication credentials are accessed
  • No financial or payment data is collected
  • No location data is tracked

3. Local Storage

User preferences such as enhancement mode, UI position, or theme selection are stored locally using Chrome’s storage API. This data remains on the user’s device and is never transmitted externally.

4. Remote Code & Analytics

PromptForger does not use analytics tools, tracking scripts, remote JavaScript execution, or third-party data collection services. All executable code is packaged within the extension.

5. Third-Party Data Sharing

PromptForger does not sell, rent, or transfer user data to third parties.

6. Changes to This Policy

Any future updates to this Privacy Policy will be reflected on this page with an updated revision date.
